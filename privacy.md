# Privacy Policy

_Effective date: 2 October 2026_

This policy applies to the personal apps listed on the [home page](index.md) (each an "App"). The owner (tongium) builds and runs them on their own computer, for their own accounts only.

## What the Apps access

An App accesses only what it needs for its listed purpose, and only for the owner's own account.

**content-creator** uses **YouTube API Services** to:
- read the owner's YouTube channel ID and title, to confirm the upload target
- upload videos to the owner's channel, with the title, description, tags and privacy setting the owner provides (`youtube.upload` scope)
- update the title, description and tags of the owner's own uploaded videos (`youtube` scope)
- update the owner's channel page settings: description, keywords, country, language and banner image (`youtube` scope)
- read the public view and like counts of the owner's own videos

It does not read watch history, subscriptions, comments, YouTube Analytics reports, email or any other data, and it accesses no data about other users.

By using an App that uses YouTube API Services, you agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms). The [Google Privacy Policy](https://policies.google.com/privacy) also applies.

## How data is used and stored

- **Sign-in tokens** (such as Google OAuth refresh tokens) are stored only on the owner's own computer, in local files that only the owner can read. They are sent only to the provider's own servers (for example, Google sign-in).
- **Content** (such as videos and their descriptions) is sent only to the service the App publishes to.
- **No sharing:** the Apps have no server, database, analytics, cookies or advertising. No data is sold, shared or transferred to anyone.

## Revoking access and deleting data

You can revoke Google access at any time on your [Google Account permissions page](https://myaccount.google.com/permissions). This makes stored tokens unusable, and deleting the local token file removes the token completely. Content already published, such as uploaded videos, stays on that service until you delete it there.
